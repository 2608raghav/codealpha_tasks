# CodeAlpha Internship Projects

This repository contains projects developed as part of the CodeAlpha Internship Program. The projects focus on web development, Natural Language Processing (NLP), and API integration.

## Projects Included

### 1. Language Translation App

A web-based application that translates text between multiple languages using a translation API.

#### Features

* Enter text for translation
* Select source and target languages
* Real-time translation
* Copy translated text
* Text-to-Speech functionality
* User-friendly interface

#### Technologies Used

* HTML
* CSS
* JavaScript
* Node.js
* Express.js
* Google Translate API

**Project Folder:** `Translation`

---

### 2. FAQ Chatbot using NLP

An intelligent FAQ chatbot that answers user queries by finding the most relevant question from a predefined FAQ dataset using Natural Language Processing techniques.

#### Features

* FAQ-based question answering
* TF-IDF Vectorization
* Cosine Similarity Matching
* Interactive Chat Interface
* Fast and accurate response retrieval

#### Technologies Used

* Python
* Flask
* NLTK
* Scikit-learn
* HTML
* CSS
* JavaScript

**Project Folder:** `faq-chatbot`
