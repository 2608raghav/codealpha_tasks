# Language Translation App

## Overview

The Language Translation App is a web application that allows users to translate text between different languages. Users can enter text, select source and target languages, and receive the translated output instantly.

## Features

* Translate text between multiple languages
* Select source and target languages
* Simple and user-friendly interface
* Copy translated text to clipboard
* Text-to-speech support for translated text
* Responsive design

## Technologies Used

### Frontend

* HTML
* CSS
* JavaScript

### Backend

* Node.js
* Express.js

### API

* Google Translate API

## Installation

1. Clone the repository.

2. Install dependencies:

```bash
npm install
```

3. Start the server:

```bash
node server.js
```

4. Open your browser and visit:

```text
http://localhost:3000
```

## Working

1. Enter text in the input area.
2. Select source language.
3. Select target language.
4. Click the Translate button.
5. View the translated output.
6. Use the Copy or Speak buttons for additional functionality.
